# Pares de contraste

Todo par de texto e fundo precisa de **4.5:1** (WCAG AA). Texto grande (a partir de 24px) e
elementos gráficos, como contornos de campos e o anel de foco, precisam de **3:1**.

A tabela é calculada ao vivo a partir das variáveis CSS. Os mesmos pares são verificados no
teste `src/design-system/tokens/contrast.test.ts`, então uma mudança de token que quebre o
contraste falha no CI.

## Atenção

- **Limão como texto:** proibido. `#C8F169` sobre branco tem 1.29:1.
- **Borda forte (`#B4BFBC`)** tem 1.89:1 sobre branco: serve só para separação decorativa. O
  contorno de campos usa `--color-border-control` (`#7E8B88`, 3.54:1).
- **Estrelas (`#E8A317`)** têm 2.17:1 sobre branco, abaixo dos 3:1 para gráficos. Sempre mostre
  a nota em texto ao lado das estrelas (ex.: “4,8 de 5”).
